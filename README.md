# MG6
*Devlog Q1: In Unity, Update() runs once per frame, but a for loop inside Update() completes all its iterations within that frame, not one iteration per frame. If the loop takes too long, the game may lag or freeze because Unity must finish the loop before moving to the next frame. A regular for loop does not automatically spread its iterations across multiple frames. In my MG6 project, I used a for loop in OnCollisionEnter2D() to call SpawnSmallRat() five times when the mother rat was attacked. All five rats are spawned during the same collision event. If I increased this to thousands of rats, the game could slow down because Unity would need to create them all in one frame.

*Devlog Q2: In my MG6 project, I tested the platform-jumping feature and successfully made the cat jump through a platform from below and land on it. However, I found a potential issue in the collision code. In Cat.cs, when _rigidbody.linearVelocity.y > 0, the code disables the cat’s entire collider using _collider.enabled = false. This allows the cat to pass through platforms while jumping, but it could also make the cat pass through other solid objects, such as walls. This happens because the code only checks the cat’s vertical speed instead of checking which object it is colliding with. A better solution would be to use Platform Effector 2D to allow one-way platform collisions without disabling the cat’s entire collider.
